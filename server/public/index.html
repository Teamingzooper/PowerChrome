PowerChrome API

Backend for the PowerChrome Chrome extension — accounts, friends, and leaderboards.

Endpoints

GET/api/healthService status + active storage backend
POST/api/account/initCreate an account. Body: { username, avatar } → { friendCode, token }
POST/api/account/getFetch your own account. Auth via { token }.
POST/api/account/updateUpdate username/avatar.
POST/api/stats/syncPush counters. Server keeps the max — never lowers a stat.
POST/api/friends/addAdd by 8-char friend code (e.g. ABCD-EFGH).
POST/api/friends/remove
POST/api/friends/list
POST/api/leaderboardBody: { kind: "combo"|"chars", scope: "friends"|"global", limit }

All counters are monotonic. Auth is per-account bearer token returned at /api/account/init — store it locally and treat it as a secret.
Storage: Upstash Redis when KV_REST_API_URL / KV_REST_API_TOKEN are set; in-process Map fallback otherwise (data resets each cold start).
